A. Lead intake

Lead intake

What happens when someone fills in, or abandons, the assessment.

1

Form Intake Router

GHL workflow: Zapier > FORM Intake Router

What it does. Sorts every completed assessment into the right lane: already booked a call, or still needs to book.

Starts when. The tag form - completed assessment is added (Zapier adds it when the Typeform assessment is finished).

Flowchart
Tag added: form - completed assessment
Wait 2 minuteslets the Calendly booking tag land first
Remove tag: form - partial
Already booked? Tags includes calendly-appointment-booked
Yes
Call Status = Booked Call
End
No
Create opportunityMain Sales Pipeline (New), stage New Lead (Opt-In)
Call Status = Form Submitted - No Call Booked
End
In plain English
  • Waits two minutes so a booking made in the same sitting is already tagged.
  • Clears the partial-form tag, because the form is now complete.
  • If they booked, the record is marked Booked Call and nothing else happens.
  • If not, a New Lead card is created in the sales pipeline and Call Status shows the gap for the setters.

GHL workflow: Client Check-in Alerts (date based)

What it does. Reminds the client success manager to check in with each client at week 3, week 6, week 9, the renewal window and program end, timed from that client's real start date.

Starts when. Every day GHL checks each tagged client's program_start_date. On start date plus 21, 42, 63, 69 or 90 days, that client enters.

In plain English
  • Nobody is enrolled by hand. The date on the record drives everything, so 47 clients with 47 different start dates each get their own schedule.
