Standard Operating Procedures
Client Onboarding Automations
Tag Reference and Workflow Guide
Owner: Operations
Audience: Closers, Client Success, Onboarding
Purpose: Tell the closer exactly which tag to apply so the correct onboarding automation fires.
1. How This Works
Every offer has its own onboarding workflow. Each workflow sends one onboarding email and nothing else. The workflow starts when one of its triggers is met.
The two triggers on every workflow
Trigger
	What it means
	Contact Tag
	A tag is added to the contact record. This is the trigger the closer controls. Add the tag and the email goes out.
	 
The tag naming standard
Each workflow has its own specific Contact Tag trigger. Use the designated tag assigned to each workflow when tagging a contact. Adding the correct Contact Tag will automatically fire the corresponding workflow for that specific contact. Ensure that the correct tag is applied to trigger the intended automation.
Closer workflow, two steps
1
	Close the sale and confirm exactly which offer the client bought.
	2
	Open the contact record and add the tag listed in the Tag to Apply column. Copy and paste it. Do not type it.
	Rules that keep this clean
One tag per client. Two tags means two onboarding emails.
Tags are case sensitive and space sensitive. Always copy and paste from this document.
If the client bought a couples package, tag the primary contact only. Do not tag both partners or the pair gets doubled up.
If you tag the wrong offer, do not remove the tag and hope. Tell Client Success immediately so they can stop the sequence.
If the offer is not on this list, do not improvise a tag. Ask Operations.
	Trigger audit
Use the exact workflow name as the Contact Tag. Adding this tag to a contact will trigger the corresponding workflow automation. Make sure the tag name matches the workflow name exactly to ensure the correct automation is activated.
