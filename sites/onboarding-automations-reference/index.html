The Process

Three steps, every closed deal

1
Mark the deal won

Move the opportunity to Closed Won and set its Status to Won. Both, not just one.

2
Fill Offer Discussed

On the contact record, select the exact program they bought.

3
Add their tags

One program tag from the table below, plus existing client. That fires their onboarding.

Rules

Five rules that keep this clean

  • One program tag per client. Two tags means two onboarding emails.
  • Copy, never type. Tags are case and space sensitive. A typo creates a new tag that triggers nothing.
  • Couples: tag the primary contact only. The Circle invite link in their email works for both partners, so forward it to the spouse. Tagging both doubles everything.
  • Never re-add a tag a client already has. It can restart their onboarding and send duplicates.
  • Tagged the wrong offer? Do not just remove it. Tell Client Success immediately so the sequence can be stopped.
