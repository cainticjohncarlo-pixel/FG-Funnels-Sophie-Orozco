When work is blocked on content or a decision, default to producing a draft/recommendation for approval rather than asking for it. Never re-ask something the client or user already answered earlier in the thread (e.g., re-asking Krissy the program session counts she had already listed).

**Why:** Asking for things that can be drafted stalls the build and pushes work onto the client; repeated questions signal the earlier answer wasn't read. The user was explicit: "Always take initiative. Avoid asking repetitive questions. If the answers are already given from the previous, do not ask again."

**How to apply:** Before including any question in a client message, check the thread for an existing answer. For missing email copy, wording choices, or descriptions: write the draft in the client's voice and present it for approval/edit. Reserve questions for things genuinely unknowable (credentials, files, account ownership, pricing that only the client can confirm).
