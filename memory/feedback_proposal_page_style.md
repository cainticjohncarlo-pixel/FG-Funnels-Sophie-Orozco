On 4 Sep 2026 the user sent a screenshot of the Sophie Orozco "Onboarding SOP by Program" page and said "I want this type of branding guidelines because it is clean." Reproduced it for the credit repair proposal.

**The style:**
- Header band: warm near-black `#1C1917`, centered. Small-caps serif eyebrow in gold `#C9A96E` with wide letter-spacing, white Playfair Display title, light gray `#CFCAC0` sans subtitle.
- Body: cream `#F6F4EF`. White cards, 1px border `#E6E1D8`, radius 14px, very soft shadow. Single centered column, max width about 900px.
- Section marker: forest green `#2E5A47` numbered circle beside a serif h2, mono subline in muted gray.
- Labels: uppercase, 0.7rem, bold, letter-spacing .13em, ink color.
- Code/tag chips: JetBrains Mono on beige `#F2EEE6` with a border. Merge fields as light-red chips (`#FBE9E7` bg, `#B3261E` text).
- Banner bars inside cards: solid green with white uppercase text (used for "texts sent by this automation").
- Accent for links and warnings: rust `#C4622D`. Hold/retry states in amber `#9A6A0B`.
- Fonts: Playfair Display (headings), Inter (body), JetBrains Mono (chips, meta).

**Why:** the user reads "clean" as generous whitespace, one column, numbered sections, and short labeled blocks. The earlier teal-on-white proposal style is not wrong, but this is now the preferred look for client-facing proposals and SOP pages.

**How to apply:** default to this style for new proposals, SOPs, and guides unless a client brand palette applies (see the reference_* brand memories). Keep the no-dash rule from [[feedback-outreach-copy-style]] and the first-person rule from [[feedback-client-email-first-person]]. First use: [[project-credit-repair-proposal]].
