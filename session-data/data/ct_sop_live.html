Continuation-Tracker System

How a client moves from the end of their program to their next one. Four automations, one pipeline, and what Krissy sees at each step.

Standard Operating Procedure · v1.0
The Big Picture

From graduation to the next program

The system starts when a client reaches the end of their initial coaching program and follows them until they either enroll in a continuation program or decline every option. Nothing here sends emails. It reads what the client does and keeps the pipeline honest.

The Four Automations

What each one does, and what starts it

1Graduation Entry

WF-CT1
What starts it
  • Program Start Date is filled in
  • 77 days have passed since that date
  • The contact has the tag existing client
What it does
  • Adds the tag graduated
  • Creates or updates a card in the Continuation Program pipeline, stage Continuation Offer, status Open
The client is officially moved from active coaching into the continuation journey.

2Continuation Engagement

WF-CT2
What starts it (any one of these)
  • The client clicks a tracked continuation link
  • An appointment is confirmed
  • The client replies
What it does
  • Checks for the tag outreach sent
  • Yes: adds continuation engaged and moves the card to Engaged
  • No: nothing happens. The workflow ends
Interested clients show up in the Engaged stage. Anyone who never received an offer is ignored.

4Continuation Declined

WF-CT4
What starts it
  • 90 or more days have passed on the date field
  • The contact has the tag graduated
What it does
  • Checks for any enrollment tag (Continue RMM, Forge, RFB, RMM Plus)
  • Enrolled: stops. Nothing changes
  • Not enrolled: adds declined-all and moves the card to Declined

Your Part

The only things a human does

A card lands in Engaged

The client clicked, replied, or booked. Reach out while the interest is warm.

A client buys a continuation program

Add the matching enrolled-… tag to their contact. That one tag records the sale and its value on the pipeline.

A card lands in Declined

Ninety days passed with no enrollment. This is the personal follow-up list.

Where It Connects

The system that runs before this one

The Client Journey System sets Program Start Date at Closed Won, sends the continuation offers on days 28, 35 and 59, and applies the outreach sent tag that automation 2 checks. It has its own SOP.

One thing to reconcile. The Client Journey emails add clients to a pipeline called Continuation Programs (stages Outreach Sent, Needs Follow-Up). This system uses Continuation Program (Continuation Offer, Engaged, Enrolled, Declined). Confirm in GoHighLevel whether these are one pipeline or two, and align the names so both systems write to the same board.
